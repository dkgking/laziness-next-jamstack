# UI text

- English only until the user asks for languages; then follow `.claude/skills/add-locale/SKILL.md`.
- This file is about the interface's own words (the 404 and error pages, form messages, small labels). The site's content, every heading, paragraph, card, and navigation label a visitor reads, lives in content files instead: see `content.md`.
- Every interface string (also `alt`, `placeholder`, `aria-label`) goes through `i18n._("Full English text")`. The variable is always named `i18n`: in a Server Component `const i18n = i18nFor(locale)` (`#/libs/i18n-server`), in a Client Component `const { i18n } = useLingui()` (`@lingui/react`). Module-level labels are descriptors marked `/*i18n*/ { id: "..." }`.
- No Lingui macros (`msg`, `t`, `<Trans>`): this site compiles none. Never build messages by concatenation or template strings.
- Numbers and dates through `#/libs/intl`.
- After changing text, run `bun run i18n:extract`, fill every non-English catalog, then `bun run i18n:check`.
